# Flutter Todo List App ✅
A clean Flutter Todo List App with Add, Delete, Mark as Done, and Mark as Important features.
Built with Flutter and Dart.

## ✨ Features
- Add new tasks
- Mark as Done ✔️ with strikethrough
- Mark as Important ⭐ highlighted in red
- Delete tasks
- Works offline, no backend needed

## 🛠️ Tech Stack
Flutter, Dart

## 🚀 How to Run
1. Clone the repo: git clone https://github.com/Sharmilaait58/flutter-todolist-app.git
2. Install packages: flutter pub get
3. Run: flutter run
